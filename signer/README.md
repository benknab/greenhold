# Signer

This test-wallet library and CLI provide signatures for Greenhold. Do not use
them for real funds or as a reference implementation.

The signer derives single-key addresses from a BIP-39 mnemonic or a BIP-32 root
seed. It signs BIP-322 messages for these script types:

| Type          | Formats (default first) |
| ------------- | ----------------------- |
| `p2pkh`       | `full`, `legacy`        |
| `p2sh-p2wpkh` | `full`                  |
| `p2wpkh`      | `simple`, `full`        |
| `p2tr`        | `simple`, `full`        |

Signatures have no time locks. The signer reads secrets only from files.

## Usage

Run these commands from the repository root:

```sh
cargo run --locked -p greenhold-signer -- address --type p2wpkh --mnemonic-file <FILE>
cargo run --locked -p greenhold-signer -- sign --type p2wpkh --message <TEXT> --mnemonic-file <FILE>
```

Without `--path`, the signer uses the BIP-44, BIP-49, BIP-84, or BIP-86 path
for the type. Use `--seed-file` for a hexadecimal BIP-32 seed, and
`--passphrase-file` with a mnemonic for a BIP-39 passphrase. One trailing LF or
CRLF is removed from the passphrase file; other whitespace is preserved.
Output is JSON. Run `cargo run --locked -p greenhold-signer -- sign --help`
for all signing options.

## Test reuse

The library exposes `derive_key`, `address`, and `sign`; signing accepts a
`bitcoin::secp256k1::SecretKey` directly. It supports the same formats as the CLI,
using SIGHASH_ALL for ECDSA and SIGHASH_DEFAULT for Taproot.

Core and host use this crate only through dev-dependencies. It does not depend
on core, host, or RISC Zero and is absent from their normal build dependency
graphs. The CLI can be built without building the guest:

```sh
cargo build --locked -p greenhold-signer
cargo test --locked -p greenhold-signer -p greenhold-core
```

Verifier tests retain frozen signatures from the original Bun/scure signer and
official BIP-322 vectors alongside signatures generated by this library.
